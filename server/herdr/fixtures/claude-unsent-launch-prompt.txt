  ## Description

  收件匣要知道有哪些卡。cc-mobile 掃描 `~/workspace/*/.obsidian.yaml`，讀出 `vault` 和 `pm.project`，再讀 vault 裡
  `pm/<project>/tasks/*.md` 的 frontmatter。這台 Mac 的 vault 名稱是 obsidian，路徑是 `~/Documents/obsidian`。vault
  名稱對路徑的對應要從 Obsidian 自己的設定讀，不要寫死。

  cc-mobile 對 vault 只讀不寫。卡片的回寫由 obw 的 hook 負責，結案和封存由 obw 負責，因為封存前的依賴檢查規則寫在 obw
  的 `skills/pm/SKILL.md`。

  「可以派發」的定義是 `status: todo` 而且 `blocked_by` 是空的，和 obw 的 frontier
  查詢一致（`skills/pm/SKILL.md:99`）。2026-10-05 決定，卡片進到 `todo`
  就代表可以送審，不另外加待核准狀態。已經有綁定的卡（有 `session` 欄位或綁定檔）不算可以派發。

  專案對 repo 不一定是一對一。2026-10 時有 13 個 repo 設了 pm 專案，其中 cyris 對到 `cyris` 和
  `cyris-archive`，shikigami 對到 `shikigami` 和 `shikigami-bridge`。一對多時，回傳所有候選 repo，讓使用者在派發時選。
